# Figures

`clip4_figure.py` draws the saved INT8 skeletons (from `research/results/pi_staged_clip4/`) on frames of the staged clip_4, which was recorded by the author with consent. It doesn't run a model. Each person is annotated with:
- confident keypoints as dots
- face keypoints below 0.5 confidence as red rings
- both head-turn measures: the ear-based yaw and the nose offset from the shoulder centre

The PNGs here are its output.
